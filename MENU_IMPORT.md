# Импорт меню «Хоровац»

Источник: https://eda.yandex.ru/r/xorovac?placeSlug=xorovac_wbm8q

Снимок от 26 октября 2026 года: 16 категорий, 117 уникальных блюд.
Подборка «Выбор пользователей» исключена: она повторяет блюда основных категорий.
109 блюд доступны; 8 десертов отмечены источником как недоступные.

Данные: `horovats-backend/internal/menuimport/data/xorovac.json`.
Фотографии: `horovats/public/images/menu/xorovac/`.
Идентификаторы категорий и блюд имеют префикс `ya-` и сохраняют ID источника.

В снимке сохранены обычные и акционные цены отдельно. Импорт по умолчанию
использует обычные цены: программа лояльности Horovatz продолжает применяться.
Акция Яндекс Еды не включается автоматически.

Источник API содержит описания у 30 из 117 блюд. Остальные описания и составы
не выдумываются. У пяти блюд сохранены необязательные группы дополнительных соусов
в `optionsGroups`; текущий сайт не поддерживает модификаторы, они не импортируются
как платные опции. Соусы основных категорий импортируются обычными блюдами.

## На VPS

Сначала изменения должны быть отправлены в GitHub. Затем:

```bash
cd /opt/horovatz
git pull --ff-only origin main
docker compose up -d --build

# Предварительный просмотр: база не изменяется.
docker compose exec backend /app/menu-import

# Заменить старое меню на 15 категорий и 109 доступных блюд.
# Перед изменением автоматически создаётся согласованная копия SQLite.
docker compose exec backend /app/menu-import --apply --replace-menu
```

Замена удаляет предыдущие категории и блюда, включая добавленные вручную.
Пользователи, заказы и история позиций заказов сохраняются. Открытые корзины
со старыми ID блюд потребуется собрать заново.

Чтобы дополнить меню или обновить ранее импортированные блюда без удаления остальных:

```bash
docker compose exec backend /app/menu-import --apply
```

Повторный импорт обновляет записи по ID и не создаёт дубликаты. Ручные изменения
импортированных названий, цен, описаний и фотографий будут перезаписаны; рекомендации
сохраняются при импорте без `--replace-menu`.

`--include-unavailable` также публикует 8 недоступных десертов: использовать только
после подтверждения их наличия. `--price promo` выбирает акционные цены источника;
скидки Horovatz при этом по-прежнему применяются, то есть могут суммироваться.

База в контейнере: `/app/data/horovats.db`. Резервная копия создаётся рядом,
её путь печатается командой. Скопируйте копию за пределы VPS, например с Mac:

```bash
# Подставить точное имя файла, напечатанное импортёром.
ssh root@SERVER_IP 'cd /opt/horovatz && docker compose cp backend:/app/data/ИМЯ_КОПИИ /root/horovatz-menu-backup.db'
scp root@SERVER_IP:/root/horovatz-menu-backup.db ./horovatz-menu-backup.db
```

После импорта обновите страницу сайта. Проверьте категории, фотографии и цены.
Автоматической синхронизации с Яндекс Едой нет; снимок импортируется явно.

## Повторная выгрузка источника

Python 3, без сторонних библиотек:

```bash
python3 scripts/export_yandex_menu.py
```

Скрипт загружает публичное меню и фотографии (до четырёх параллельных запросов),
проверяет цены, уникальность ID и JPEG-файлы. При ошибке загрузки новый JSON
не записывается. После обновления проверьте изменения перед импортом.

Проверка импортёра:

```bash
cd horovats-backend
go test ./internal/menuimport ./cmd/menu-import
```
