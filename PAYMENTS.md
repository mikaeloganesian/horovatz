# Обновление статуса оплаты

После возврата из ЮKassa страница `/payment/return` запрашивает статус заказа.
Если заказ еще ожидает оплаты, сервер получает платеж из API ЮKassa по сохраненному
ID и проверяет ID платежа, `metadata.order_id`, сумму и валюту RUB.
Оплата подтверждается только при `status=succeeded` и `paid=true`.
`waiting_for_capture` не считается завершенной оплатой.

Подтверждение обновляет заказ и ставит Telegram-уведомление в очередь в одной
транзакции. Повторные проверки и webhook не создают повторные события оплаты.
Проверка не создает новый платеж и не списывает деньги повторно.

Страница продолжает проверку каждые 2 секунды, затем каждые 5 секунд, пока открыта.
При длительном ожидании есть кнопка «Проверить сейчас».
Если API ЮKassa временно недоступен, статус не меняется на оплаченный или отмененный;
сервер возвращает 502, страница повторяет проверку.

Webhook остается нужен, чтобы статус обновлялся, даже когда покупатель не вернулся
на сайт. В настройках уведомлений магазина ЮKassa укажите:

- URL: `https://horovatz.ru/api/payments/yookassa/webhook`
- События: `payment.succeeded`, `payment.canceled`.

Обработчик перепроверяет платеж через API и не доверяет статусу из тела webhook.

Обновление VPS:

```bash
cd /opt/horovatz
git pull --ff-only origin main
docker compose up -d --build backend web
```

После обновления можно открыть прежнюю страницу возврата с номером заказа и токеном:
уже завершенный платеж будет проверен и сохранен, даже если webhook ранее не пришел.
Повторная оплата для этой проверки не требуется.
